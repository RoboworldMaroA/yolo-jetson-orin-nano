This programms uses a new docler image: yolo_web_easyocr
It has pre installed easyOCR and Flask

Created file requirement.txt and added library that will be instaled together with the docker

  flask
  easyocr

In Doclerfile add a line that allows to instal from this location:

  FROM ultralytics/ultralytics:latest-jetson-jetpack6
  COPY requirements.txt /app/
  RUN python -m pip install --no-cache-dir -r /app/requirements.txt
  EXPOSE 5010

Now build new Image:
docker build -t yolo_web_easyocr . 

Check created Images: 
  docker images

See details of the image
docker images yolo_web_easyocr


Check what containers are running:
sudo docker ps -a
